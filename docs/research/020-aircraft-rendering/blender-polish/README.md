# Blender 모델링 마감본

[완성 .blend](Aircraft-Studio.blend) · [전체 렌더](studio-render.png) · [동일 조건 전후](comparison.jpg) · [실측값](measurements.json)

부품별 아틀라스에서 만든 [10파츠 조립본](../part-atlases/Aircraft.blend)을 별도로 복제해 작업했다. 동체는 복제 원본의 횡단면을 샘플링해 곡면을 정리했다. 주날개와 앞날개의 평면 윤곽은 전체 기체의 TOP, 꼬리의 기울기는 FRONT에 맞췄다. 캐노피는 닫힌 돔과 같은 오브젝트 안에 테두리와 솟은 띠를 모델링했다. 엔진 덮개 두 개는 기존의 오목한 흡입구와 배기구를 유지한다. 새 표면의 아틀라스 투영용 UV와 베이크용 UV는 분리했다.

파일은 0프레임에 열린다. 48프레임은 분해 상태, 96프레임은 복귀 상태다. 독립 Blender 프로세스에서 각 부품 변환, 조립 시 연결과 이미지 패킹을 검사했다. 주날개 두께는 원래 실험의 TOP 픽셀 (94, 105)에서 양쪽 표면에 수직 광선을 쏴 측정했다. 원본 사진과의 일치도는 등록한 한 카메라에서의 전경 IoU다. 4면 기준은 첫 실험의 전체 기체 아틀라스다.

[렌더 QA](qa.json)는 파츠별로 수행했다. 조립체의 지면 위 오프셋은 기체의 기존 좌표계를 따른다.
