# 날개 뿌리 접합부 마감

[Blender 파일](Aircraft-Industrial.blend) · [전후 비교](comparison.jpg) · [전체 렌더](aircraft.png)

원본 Studio 모델을 복제하고 엔진 덮개 두 개에만 돌출 접합부를 합쳤다. 각 가장자리 밑에 살짝 들어간 어두운 면을 만들어 조립 상태에서 그림자가 이어지게 했다. 패널 이음새는 덮개와 접합부에서 같은 좌표로 읽는 색·높이 맵이다. 엔진 덮개를 분해하면 이음새와 단차도 같이 움직인다. 이 경계는 콘셉트 모델의 디자인 해석이다.

날개 앞전에는 채도가 낮은 티타늄색과 넓게 퍼지는 반사를 사용했다. 저장 파일을 다시 열어 조립 시 10개 파츠의 접촉, 48프레임 분해 이동량 및 96프레임 복귀를 확인했다. 날개 정점 좌표 전체가 원본과 같았고 등록 카메라에서 사선 외곽 마스크도 일치했다. 접합부의 새 면과 원래 덮개는 재질별로 UV를 공유하므로, 하나의 맵에 통합 베이크할 때는 별도 UV 패킹이 필요하다. [수치](measurements.json) · [파츠별 QA](qa.json)
