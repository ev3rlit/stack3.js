# 같은 메시의 표면·거칠기·두께 비교

[날개 두께를 유지한 적용 전후](wing-profile.jpg) · [확대 캡처](detail-comparison.jpg) · [기체 전체](whole-aircraft.jpg) · [실측값](measurements.json)

[단면 가이드 적용 모델](../guide-comparison/models/guide-on.glb)의 3,600개 삼각형으로 EEVEE에서 촬영했다. 이전 스튜디오에 낮은 각도의 광원 하나를 추가하고 모든 비교 쌍에 같은 카메라·조명·베이스 컬러·금속성 0.22를 적용했다. 아래 값은 차이를 보기 위한 예시로 정했다.

- **거칠기**. 기본값 0.48과 [부위별 거칠기 맵](roughness.png)을 비교했다. 캐노피는 0.14, 주 도장면은 0.62다. TOP에 정렬한 마스크이므로 반사 차이는 정투상도 위에서 저작한 구역을 따른다. 원본의 베이스 컬러에는 이미 일부 반사광이 그려져 있다.
- **표면 요철**. TOP에 보이는 날개 패널선을 따라 홈과 몇 개의 체결점을 그린 [높이 맵](panel-height.png)으로 셰이더의 범프 노멀을 바꿨다. 두 맵 모두 선형 데이터로 읽는다. 높이 맵은 추정한 표면 장식이며 실제 깊이 실측 자료는 없다.
- **별도 두께 실험**. 스택에서 만든 모델의 렌더용 복사본에서 바깥 주날개 중간 구역의 위·아래 정점을 단면 중심으로부터 최대 1.7배 벌렸다. 루트와 끝에서는 원래 형상으로 부드럽게 전환했다. TOP 영상 좌표 (94, 105)에서 광선으로 위·아래 면을 찾아 잰 결과는 0.1313 → 0.2208 장면 단위였다. 수정은 비교용 셰이프 키이며 두께 설계값을 뜻하지 않는다.

전체 적용본은 거칠기와 범프만 사용한다. 원본과 적용본의 모든 정점 좌표가 같고, TOP 영상 좌표 (94, 105)에서 두께는 모두 0.1313 장면 단위였다. 사선 전체와 정면 날개 확대에서 기준과 전경 마스크가 완전히 겹쳤다. 별도의 두께 과장 실험에서만 날개 확대 마스크 IoU가 83.50%였다. 이 값은 변화량 확인용이며 정답 모델 대비 정확도와는 별개다.

상위 실험의 Python 의존성 및 Blender 5.2.4를 사용한다. 이 폴더에서 임시 출력 디렉터리를 인자로 순서대로 실행한다.

```sh
work=$(mktemp -d)
python maps.py "$work"
blender -b --factory-startup --python-exit-code 1 -P render_detail.py -- "$work"
python compare.py "$work"
```
