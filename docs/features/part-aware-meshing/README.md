# 부품별 스프라이트 스택 메시 생성

**상태는 구현 전 명세다.** 하나의 에셋 안에서도 날개에는 두께를 잘 보존하는 기법을, 캐노피에는 곡률이 부드럽게 이어지는 기법을 선택할 수 있게 한다. 이번 범위는 아래 여섯 피사체 유형과 14개 기법이다. 기본 Marching Cubes와 Surface Nets는 현재 구현을 사용하고, 나머지 12개를 추가한다. 기존 `voxel`은 블록 방식의 별도 비교 기준으로 사용한다. [현재 추출기](../../../packages/core/src/reconstruct.ts) · [메시 기법 조사와 기존 부품 실측](../../research/030-meshing-methods/README.md)

## 피사체별 구현 범위

| 피사체 | 비교할 메시 기법 | 선택 기준 |
| --- | --- | --- |
| 날개·지느러미·얇은 판 | 단면 로프트, 상하 높이장, 기본 Marching Cubes | 뿌리·중간·끝에서 두께를 얼마나 보존하는가. 입력 단면 사이에서 부풀거나 끝이 끊기는가. |
| 캐노피·병·둥근 외장 | Surface Nets, 곡면 로프트, 축 회전 | 곡면의 하이라이트가 매끈하게 이어지는가. 축 회전의 경우 실제 부품이 회전대칭인가. |
| 각진 하우징·가전 외장 | Extended Marching Cubes, Hermite Dual Contouring | 둥근 부분을 따라가면서 모서리 위치와 각도를 얼마나 보존하는가. 경계 법선의 품질이 충분한가. [Dual Contouring 원 논문](https://www.cs.rice.edu/~jwarren/papers/dualcontour.pdf) |
| 머그 손잡이·분기 배관·관통구 | 위상 보정형 Marching Cubes, 분기 대응 단면 연결, 경로 스윕 | 입구에서 출구까지 빈 공간이 이어지는가. 하나의 단면이 둘로 갈라지거나 다시 합쳐지는 위치가 맞는가. [단면 분기 연구](https://graphicsinterface.org/wp-content/uploads/gi1991-32.pdf) |
| 수평·수직 단면을 함께 확보한 피사체 | 비평행 단면 곡선망 재구성 | 같은 위치를 지나는 실제 절단선들이 일치하는가. 결과 메시를 다시 잘랐을 때 두 방향의 두께와 오목부가 함께 재현되는가. [비평행 단면 곡선망 원 논문](https://www.cs.wustl.edu/~taoju/research/eg_paper_final.pdf) |
| 블록 스타일·정확한 셀 경계가 필요한 모델 | Greedy Meshing, Monotone Meshing | 노출 셀 면과 색 경계를 보존하는가. GLB로 내보낸 후 삼각형·정점 수가 각각 얼마나 줄어드는가. [두 방식의 비교](https://0fps.net/2012/07/07/meshing-minecraft-part-2/) |

## 입력과 출력

1. 피사체 설명이나 레퍼런스 사진에서 시작하면 부품별 4면 아틀라스를 생성하고, 각 아틀라스에서 스프라이트 스택을 저장한다. 이미 저장된 스택은 바로 사용한다.
2. 부품마다 `stack3 mesh <부품 스택> --mesh-method <기법> --output <부품.glb>`에서 기법 하나를 선택한다. 옵션을 생략하면 현행 기본값 `marching-cubes`를 사용한다. 같은 스택에 여러 기법을 실행해 결과를 비교할 수 있다.
3. 각 기법은 동일한 `stack.json`과 `stack.png`를 읽는다. 형상은 저장된 점유 마스크(알파 128 이상), 실제 축별 간격과 선택한 가이드를 사용한다. 메시마다 원래 크기·방향·피벗을 보존하고 저장된 RGB를 표면에 투영한다.
4. 스택만으로 정해지지 않는 회전축·스윕 경로·독립 단면은 부품별 가이드로 받는다. 스택에서 유도한 값과 사용자가 준 값을 구분한다. 필요한 입력이 없거나 모순되면 해당 부품과 원인을 알린다.
5. Blender에서 GLB를 열어 기존 마운트에 조립하고 검토한다. 단면 제어점, 모서리, 토폴로지를 직접 다듬는 작업이 필요할 때 이 단계에서 커스텀한다.

## 새로 구현할 12개 기법

아래 이름은 구현할 동작을 구분하기 위한 것이다. 각 기법을 CLI에 연결할 때 도움말과 스킬에 실제 옵션 이름과 필요한 가이드를 함께 등록한다.

| 기법 | 구현할 동작 | 따로 다뤄야 할 경우 |
| --- | --- | --- |
| 단면 로프트 | 지정한 축을 따라 스택의 단면을 읽고, 이웃 윤곽의 대응점을 직선으로 이어 끝을 닫는다. | 시작점·진행 방향을 맞춰 비틀림을 방지한다. 루프 수가 바뀌는 구간은 분기 대응이 필요하다. |
| 상하 높이장 | 두께 축의 각 열에서 첫 점유면과 마지막 점유면을 찾아 두 표면과 테두리를 연결한다. | 한 열에 점유 구간이 여럿이면 사이가 메워진다. 해당 열을 감지해 이 표현의 적용 한계를 알린다. |
| 곡면 로프트 | 여러 단면을 보간하는 매끄러운 곡면을 만들고 삼각화한다. | 가이드가 있는 단면과 그 사이의 중간 단면을 모두 검사해 과도한 팽창을 찾는다. |
| 축 회전 | 단면에서 얻은 옆모습을 지정한 축 둘레로 회전해 표면을 만든다. | 병 입구처럼 내벽이 있는 단면과 축에 닿는 극점을 처리한다. 비대칭 손잡이는 별도 부품으로 다룰 수 있다. |
| Extended Marching Cubes | 경계 교차점과 법선으로 셀 안의 날과 꼭짓점을 추정해 기본 MC 표면에 특징 정점을 만든다. | 계단식 점유 마스크에서 추정한 법선이 매끈한 면에 거짓 능선을 만드는지 확인한다. |
| Hermite Dual Contouring | 교차점과 법선이 정하는 평면들에 대한 오차를 최소화해 경계 셀의 대표점을 구하고 인접 셀을 잇는다. | 평행한 법선, 불안정한 해, 한 셀에 가까이 놓인 두 겹을 검사한다. |
| 위상 보정형 Marching Cubes | 면과 셀 내부의 모호한 경우를 모두 판정하는 검증된 MC33 계열 구현을 사용한다. | 보간장의 연결성과 대조한다. 스택에서 이미 막힌 구멍에는 추가 단면 정보가 필요하다. |
| 분기 대응 단면 연결 | 층 사이에서 루프의 생성·소멸·분할·병합을 추적해 대응하는 경계를 삼각화한다. | 바깥 윤곽과 안쪽 구멍을 구분하고, 서로 가까운 독립 부품 사이에 잘못 생긴 연결을 검사한다. |
| 경로 스윕 | 중심 경로를 따라 단면을 이동·회전해 표면을 만든다. 속이 빈 관은 안팎의 루프를 함께 운반한다. | 급한 굴곡에서 단면 뒤집힘과 자기 교차를 확인한다. Y자 접합부는 분기 대응으로 다룬다. |
| 비평행 단면 곡선망 재구성 | 각 절단 평면의 위치·방향과 닫힌 곡선을 부품 좌표계에 등록하고 교차 제약을 만족하는 표면을 만든다. | 투영 실루엣과 실제 절단선을 구분한다. 같은 스택을 다른 축으로 다시 자른 결과는 독립 관측으로 세지 않는다. |
| Greedy Meshing | 같은 평면·방향의 노출 셀 면을 직사각형으로 합친 뒤 삼각화한다. | 합친 면의 UV가 원래 도색을 유지하는지, 긴 변 중간의 T 접합이 출력에서 균열을 만드는지 확인한다. |
| Monotone Meshing | 노출 셀 면의 평면 영역을 단조 다각형으로 나누고 삼각화한다. | 오목 윤곽·구멍·분리된 섬의 면적이 일치하는지 확인한다. Greedy와 동일한 출력 조건에서 정점 수도 비교한다. |

## 구현 완료를 판단하는 방법

| 검증 입력 | 확인할 결과 |
| --- | --- |
| 저장소의 카나드·날개·캐노피 스택 | 같은 원본으로 후보 GLB를 각각 만든다. 축별 셀 간격을 반영해 지정 위치의 두께 오차를 장면 단위로 기록한다. 동일 카메라의 목표 화면 크기와 근접 단면을 함께 비교한다. [기존 부품 스택](../../research/020-aircraft-rendering/part-atlases/stacks) |
| 정답을 아는 합성 스택 | 모서리가 있는 상자, 관통구, Y자 분기, 교차 단면을 가진 오목체를 사용한다. 기대한 모서리 위치·빈 공간의 연결·단면 루프 수와 재추출 결과를 대조한다. |
| 계단·구멍·색 경계가 있는 블록 | `voxel`을 기준으로 방향별 노출 면의 합집합과 색 경계를 비교한다. Greedy와 Monotone에서 최종 GLB의 삼각형·정점 수를 각각 기록한다. |
| CLI 출력과 Blender 재임포트 | GLB를 다시 열어 크기·피벗·방향·텍스처를 확인한다. 닫힌 부품에서는 경계 누락과 뒤집힌 면을 검사한다. 기존 스택 번들과 기본 옵션의 회귀 테스트를 포함한다. |

기법을 비교할 때는 같은 입력 스택·가이드·재질·카메라를 사용한다. 별도 가이드가 필요한 기법은 어떤 정보를 추가했는지 남긴다. 스택과의 일치도, 원본 이미지와의 실루엣 일치도, 최종 삼각형 수는 각각 기록한다. 이 셋은 서로 다른 품질을 측정한다.
