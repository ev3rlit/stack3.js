# Web App

The web app will teach the workflow and offer a browser playground. It will reuse the viewer, Worker, and export tools.

## Required Behavior

- Show the input conventions, CLI examples, and the difference between mesh and stack output.
- Provide sample assets for trying import, reconstruction, and export.
- Keep the browser playground on the same reconstruction and validation path as the viewer.

## Completion Check

A visitor can open a sample, adjust it, switch output targets, and save a result without needing the CLI. The documented command examples describe the same workflow.
