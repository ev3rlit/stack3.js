# 병아리 64층 단면 복원 실험

[원본 4뷰](../chick-4view.png) · [복셀](voxel.glb) · [선택한 경로의 QEM 직전 메시](L.glb) · [최종 무채색 1,600면 GLB](chick-contour-loft-1600.glb) · [단계별 실물 렌더](stages.jpg) · [360도 비교](turntable.mp4) · [와이어프레임 비교](ablations.jpg) · [수평 단면](cross-sections.png) · [Triple-Dexel 깊이 결합 실험](depth/README.md)

단일 아틀라스와 원래 32×31×64 점유 스택을 사용했다. 원래 형상은 네 방향 마스크로 깎은 볼륨에 각 높이의 타원 마스크를 적용한 결과다. TOP도 형상을 제한한다. 순수 실루엣 교차와 round 클리핑을 비교하는 별도 스택은 hull-control에 있다. 빈 여백, 실제 모델 크기 기준 Gaussian sigma 0.03322, 높이 1, UV 투영 방식과 조명은 이전 64층 벤치마크에 맞췄다. A.glb는 이전 64층 최종 GLB와 SHA-1까지 일치했다. 모든 비교 이미지는 형상만 보이도록 Blender에서 동일한 재질로 렌더했다.

## 결과 해석

* B→A에서 QEM은 12,624면을 1,598면으로 줄였고 몸통 반지름 잔차 RMS는 약 1.9% 증가했다. 감축 이전부터 각도에 따른 단면 불규칙성이 남아 있었다.
* B, R, C, D는 동일한 거리장과 큐빅 보간을 사용한다. -raw 대조군은 Taubin과 QEM을 모두 끈다. 기본 Hermite DC도 매끄러운 셀에서 중심점 정규화를 사용한다. R은 모든 셀에서 제약 수에 비례한 0.5 가중치를 준다. MC는 Lewiner 연결성과 스플라인 모서리 교점을 쓴다.
* E64와 E128은 같은 평활화된 장의 물리적 범위에 64³ 또는 128³개의 내부 샘플을 둔다. 64층 아틀라스를 다시 관측하지 않는다. 큐빅 재샘플링으로 세밀해진 삼각분할도 원래 단면의 근본 형태를 유지했다.
* F는 원본 FRONT와 LEFT에서 각 높이의 전체 폭과 중심을 측정해 지수 2의 타원을 만든다. F3은 지수 3이다. G는 같은 64개 단면의 경계 파라미터를 높이 방향 3차 B-spline으로 적합한다. 이 연속 암시 함수는 정확한 유클리드 거리 함수가 아니다. z=0.26~0.80에서 몸통을 대체하고, z=0.16~0.26과 0.80~0.91에서 원래 장과 부드럽게 혼합한다. 측면에서 부리가 나온 높이의 전체 폭을 둘레에 적용해 띠가 생겼고 TOP 일치도가 낮아졌다.
* L은 E64 기준장의 몸통 단면에서 높이별로 96개 방위의 바깥 반지름을 측정한다. 한 방위에 내부 구간이 여러 개면 중단한다. 52개 높이에서 각도 방향 주기 3차 B-spline 기저 16개와 높이 방향 3차 B-spline을 적합한다. 발과 머리 끝에는 원래 장을 유지한다. L-lod에서 A보다 몸통 흔들림이 약 8.5% 감소했고 4뷰 평균 윤곽 일치도는 0.36%p 낮아졌다.
* H는 G에 목표 에지 길이 0.038의 균일 등방성 리메싱을 적용한다. Hproj는 같은 결과에 원래 암시 함수의 영점으로 투영하는 단계를 더한다. G→H→Hproj에서 삼각형 분포는 개선되지만 타원의 띠는 유지된다. LR-lod와 LA-lod는 각도별 윤곽 로프트에 각각 균일 및 적응형 리메싱과 재투영을 적용했다. 이 입력과 파라미터에서 두 최종 GLB는 동일했다. 최종 선택은 4뷰 및 발 윤곽을 조금 더 유지하는 L-lod다.

## 재현

이 디렉터리에서 실행한다. YAML과 등록된 입력장이 포함되어 있으므로 최종 결과만 다시 만들 때는 마지막 명령만 필요하다.

```sh
../../../../../node_modules/.bin/tsx fit-views.ts
uv run --with numpy==2.2.6 --with scipy==1.15.3 --with pillow python sections.py
uv run --with numpy==2.2.6 --with scipy==1.15.3 --with pillow python contour_loft.py
python3 recipes.py
node ../../../../../apps/cli/bin/stack3.mjs pipeline run L-lod.yaml
```

모든 조건을 실행하려면 각 YAML을 같은 CLI에 전달한다. measure.py는 출력 메시에서 metrics.json을 작성한다. review.py는 Blender에서 지정한 폴더에 같은 카메라의 단색 렌더와 와이어를 저장한다. plates.py는 렌더 폴더에서 비교 시트와 영상을 조립한다. Blender 리임포트 시의 경계 에지·비다양체·퇴화면 등은 mesh-checks.json에 있다.
